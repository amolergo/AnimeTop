# KawaiiFlex iOS — исходники 0.1.0

Проект ещё **не скомпилирован и не проверен в симуляторе iOS**: текущая машина Windows, доступа к Mac нет. Готового IPA и TestFlight сейчас нет. Изменение размера страницы в браузере не считается проверкой нативного приложения.

Интерфейс SwiftUI: каталог с поиском и переключением Anime/Mult/Кино, коллекция, карточки и серии, связанные части, общий аккаунт и отметки просмотренного. Друзья, переписка, отзывы, подписка и Мира открываются в WKWebView с синхронизацией cookie своего сервиса. Плеер использует MobileVLCKit 3.7.5 для AVI/MKV/AC3 и TorrServerKit MatriX.150 внутри процесса. Запросы к локальному движку используют отдельную сессию без аккаунтных cookie. При уходе в фон воспроизведение ставится на паузу.

## Первый настоящий прогон

Нужен Mac с полным Xcode, Go, Node/Yarn, XcodeGen и CocoaPods. Для самого симулятора платная подписка Apple Developer не нужна.

1. Выполнить `bash prepare-on-mac.sh`. Скрипт берёт исходники официального TorrServer MatriX.150 и перед сборкой добавляет явную привязку HTTP к 127.0.0.1. Готовый upstream XCFramework напрямую не используется: в его mobile-обёртке список IP пуст.
2. Открыть `KawaiiFlex.xcworkspace`. Выбрать iPhone Simulator и выполнить Product → Test. Сначала устранить возможные ошибки Swift/SDK: на Windows они проверить не могли.
3. Проверить каталог, вход, отметки серий, Дарью S2E2/S2E3, переключение дорожек и субтитров, паузу при уходе домой, поворот экрана и общую библиотеку с сайтом/ТВ.
4. Для устройства настроить собственную подпись Apple в Xcode. Для TestFlight/App Store нужны Apple Developer Program и App Store Connect; сертификаты и ключи в исходники не добавлять.

Символы StartServer/StopServer/IsRunning сверены с заголовком официального XCFramework, SHA-256 архива `bbf4eeecafa47be4ea2b25291c2d913b9de849c2b64a4b1ff686ea7423552b2a`. Проверка заголовка не подтверждает компиляцию или воспроизведение на iOS.

Исходники зависимостей: https://github.com/YouROK/TorrServer/tree/MatriX.150 и https://code.videolan.org/videolan/VLCKit. Лицензии и исходники зависимостей должны сопровождать распространяемую сборку. Требуется отдельная проверка ограничений App Store перед публикацией; загрузок или отправок на проверку из этого проекта не выполнялось.
